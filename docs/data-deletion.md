# Data Deletion and Local Data Removal

Last updated: 2026-06-26

ViBRo Navigator does not provide user accounts and does not operate a
developer-hosted user-data server. There is no app account to delete.

This page explains how to remove local data created by the app.

## Delete all local app data

Use Android system settings:

1. Open Android Settings.
2. Open Apps.
3. Select ViBRo Navigator.
4. Open Storage.
5. Choose Clear storage or Clear data.

You can also uninstall the app to remove app-managed local data.

## Delete individual app data

Inside ViBRo Navigator, you can remove:

- POI history entries from the destination or stop suggestion list.
- Saved routes from the saved-route restore dialog.
- The optional Google Maps API key by opening the Google Maps API key setting
  and saving an empty value.
- Optional logging by turning Log enabled off in the About page.

## Delete exported files

Database backups, GPX route exports, and files shared with another app are
created only when you explicitly export or share them. They are stored wherever
you or the receiving app chose to save them. Delete those files from that
location if you no longer want to keep them.

## Delete optional logs

Optional logs are local files created only when Log enabled is on. They can be
removed by clearing app storage, uninstalling the app, or deleting the app's log
files from Android app-specific storage where your file manager allows access.

## Requests

Because ViBRo Navigator has no accounts and no developer-hosted user-data
server, most deletion is performed directly on your device. Questions can be
submitted through:
